## Retention and digest contract

Fixed supervisor storage is `<trial-parent>/.finalization/<trial-id>/` containing
`artifact/` and `finalization.json`. The issuer overrides any requested retained
path. The code, producer `<trial>/repo`, grader exchange and private root cannot
overlap. No producer or grader receives this root. This filesystem layout is an
**inert supervisor-owned fixture convention**, not proof of mount/UID isolation.
An operational adapter must provide real private storage outside both mounts;
merely placing this sibling under a broadly mounted evidence parent is forbidden.

The bounded exclusive record contains identity/ownership commitments, completed
comparator state and binding, original file/directory manifest, approved Git
digest, normalized materialization digest, and original-mode Snapshot. Raw bytes
live only in the independently imported private tree. Existing importer bounds
remain 2000 entries, 1000 files, 32 levels and 8 MiB including Git metadata;
record JSON is separately bounded to 16 MiB. Re-audit checks private root/record
ownership and permissions, no links, bounded stable descriptor reads, exact root
entries, record hash, identity, comparator/evidence binding, original manifest
content/modes, normalized materialization, approved Git bytes and Snapshot files.
Index/status/diff are the bound owner-exported Snapshot, not reconstructed by
executing Git during audit. Their owner hash and result-bound record hash prevent
substitution; the canonical final Snapshot digest enters the native receipt.

Owner `snapshotDigest` is SHA-256 of **raw JSON.stringify output**. It is not
`manifest.digest`, which canonicalizes object keys. Re-audit validates the former
as raw JSON, separately using canonical digests for result/native receipt binding.
Original executable modes survive normalized 0600/0700 copies. `changedPaths`
and baseline/final index equality derive the existing scope/preservation fields;
`review` remains `pending`, `taskSuccess` remains null. No task-success approval
is implied by behavior=true. The native inventory adds logical `finalization.json`
for V3 only; its actual file is in the fixed private root, not the trial exchange.
The record commits the imported tree that is reloaded on every audit.
