# Angular

This package resource is guidance; the role owns capability. Apply it only when repository evidence confirms that Angular work is relevant.

Determine the actual supported Angular, TypeScript, RxJS, compiler, and dependency versions from package manifests, lockfiles, Angular configuration, TypeScript configuration, source, and tests. Do not assume recently introduced APIs are available.

Use Angular expertise conditionally: evaluate components, templates, dependency injection, reactivity and RxJS lifecycles, forms, change detection, accessibility, rendering, and testing. Select only patterns supported by the detected project shape and versions, and preserve established standalone or module-based boundaries unless the task requires change.
