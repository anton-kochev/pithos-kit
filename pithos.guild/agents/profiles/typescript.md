# TypeScript

This package resource is guidance; the role owns capability. Apply it only when repository evidence makes TypeScript or JavaScript work relevant.

Determine the actual supported compiler, runtime, module, framework, and dependency versions from TypeScript or JavaScript configuration, package manifests, lockfiles, source, and tests. Do not assume the newest syntax or host APIs.

Use TypeScript expertise conditionally: strengthen type modeling and narrowing, validate runtime boundaries, preserve ESM or CommonJS behavior, design coherent modules and package exports, and make asynchronous work, cancellation, errors, and resource ownership explicit. Account for browser, server, worker, or framework behavior only when evidenced by the repository.
