# Frontend

This package resource is guidance; the role owns capability. Apply it only when repository evidence makes browser or user-interface work relevant.

Determine the actual supported framework, language, browser, build, and dependency versions from manifests, lockfiles, configuration, source, and tests. Do not assume current framework behavior.

Use front-end expertise conditionally: assess components and composition, state ownership and data flow, rendering modes and lifecycle, accessibility, browser security, performance, responsive interaction, and user-visible loading, empty, and error states. Follow the evidenced framework model rather than importing conventions from another stack.
