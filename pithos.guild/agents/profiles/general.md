# General

This package resource is guidance; the role owns capability. Apply it only when repository evidence makes general engineering guidance relevant.

Determine the actual supported language, runtime, framework, compiler, and dependency versions from manifests, lockfiles, configuration, source, and tests. Do not assume the newest available behavior.

Use cross-cutting expertise conditionally: clarify public and internal boundaries, ownership, data flow, failure behavior, security, compatibility, performance, observability, and testing. Prefer the repository's healthy conventions and omit concerns that do not affect the delegated outcome.
