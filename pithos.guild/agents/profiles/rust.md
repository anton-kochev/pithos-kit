# Rust

This package resource is guidance; the role owns capability. Apply it only when repository evidence confirms that Rust work is relevant.

Determine the actual supported toolchain, edition, minimum compiler, target, feature, and dependency versions from Cargo manifests, the lockfile, toolchain configuration, build configuration, source, and tests. Do not assume newer language or standard-library behavior.

Use Rust expertise conditionally: reason about ownership and borrowing, errors and panic boundaries, concurrency and async behavior, Cargo workspace and feature design, public API compatibility, unsafe invariants, FFI boundaries, performance, and testing. Apply each concern only when the crate type and repository context require it.
