# .NET

This package resource is guidance; the role owns capability. Apply it only when repository evidence confirms that .NET or C# work is relevant.

Determine the actual supported target frameworks, language, runtime, SDK, and dependency versions from solution and project files, central build configuration, lockfiles, SDK selection, source, and tests. Do not assume newer platform APIs or language features.

Use .NET expertise conditionally: assess project boundaries and runtime hosting, dependency injection lifetimes, persistence and transaction ownership, asynchronous and cancellation behavior, nullability, configuration, security, and testing. Apply web, worker, desktop, cloud-function, or data-access concerns only when the repository demonstrates them.
